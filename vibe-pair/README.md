# Vibe Pair 💜

A full-stack dating + discovery + realtime-chat MVP.

## Stack
React + Vite, Tailwind CSS, Node.js + Express, Supabase Auth, PostgreSQL, Supabase Realtime.

## Setup
1. Create a Supabase project.
2. Run `supabase/schema.sql` in Supabase SQL Editor.
3. Copy `frontend/.env.example` to `frontend/.env` and add Supabase credentials.
4. Copy `backend/.env.example` to `backend/.env`.
5. Run frontend:
   `cd frontend && npm install && npm run dev`
6. Run backend:
   `cd backend && npm install && npm run dev`

## Important
This is an MVP foundation. Video calling, biometric identity verification, payments, push notifications, AI, Redis and AWS infrastructure should be added after the core product works.
